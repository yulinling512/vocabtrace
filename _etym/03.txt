decorate|拉丁 decus 是「体面、光彩」。把东西装点得更有面子；给人挂勋章，也是给人添光彩。
decrease|de-（向下）+ crescere（长），同源 increase、crescent。往下长。
deed|古英语 dæd，与 do 同源。做出来的那件事；盖了章的那一件，就是契约。
defect|de- + facere（做），同源 perfect。没做好，差了一截。
defend|de- + fendere（打），同源 offend。把打过来的挡回去。
degrade|de-（向下）+ gradus（步、级），同源 grade。把级往下调。
delay|古法语 laier 是「留下、放松」。把事往后留着。
delete|拉丁 delere 是「抹去、销毁」，原义是涂掉字迹。
deliberately|de- + libra（天平，同源「磅」）。放到天平上称过才做，所以既是「故意」，也是「不慌不忙」。
delicate|拉丁 delicatus 是「令人愉悦、精细」，同源 delicious。细到一碰就坏。
delight|拉丁 delectare 是「引诱、取悦」。心里被勾得发亮。
deliver|de- + liberare（放出），同源 liberate。把东西放出手，把话放出去就是演讲。
democratic|demos（人民）+ kratos（权力）。人民掌权。
demolition|de-（反向）+ moliri（堆建），同源 molecule。把堆起来的推倒。
demonstrate|de- + monstrare（指给人看）。同源 monster，原义是「示警之物」。指出来给人看，站到街上给人看就是示威。
depart|de- + pars（部分、分开）。从原来的地方分开走。
desert|de- + serere（连接），同源 series。把连接解开、把人丢下；断开的那片地，就是沙漠。
deserve|de- + servire（服务），同源 serve。干完了活，就该拿到那份。
desire|de- + sidus（星）。仰头盼着那颗星。
desperate|de- + sperare（希望），同源 prosper。希望被抽走。
destination|de- + stinare（站定），同源 destiny。定好要停的那一站。
destruction|de-（反向）+ struere（建），同源 construct。把建的拆掉。
determine|de- + terminus（边界），同源 terminal。把边界划死，所以是确定，也是下决心。
devote|de- + vovere（誓愿），同源 vow。立下誓把力气交出去。
disability|dis-（不）+ habilis（能），同源 able。不能的那个状态。
disappoint|dis-（撤）+ appoint（任命、指定）。把定好的人撤了，让人落空。
distant|dis- + stare（站），同源 stand。站得远远的，人也处得远。
distinct|dis- + stinguere（刺出记号），同源 instinct。刺出记号才分得清。
distinguish|同 distinct，stingu 是「刺、戳」，同源 extinguish。戳出记号才能分开。
eager|拉丁 acer 是「尖锐、激烈」。心尖上挂着这件事。
economic|oikos（家）+ nomos（管理）。管好一个家，后来指一国的生计。
embarrass|em- + barra（栏杆），同源 barrier。在面前横一道栏，进退都不自在。
emergency|e- + mergere（沉），同源 submerge。突然从水里浮出来的那件事。
emotion|e- + movere（动），同源 motion、motor。心里被推着动起来。
emphasis|en- + phainein（显现），同源 phase、phenomenon。让某处显出来。
enable|en-（使）+ able（能）。使它能。
engage|en- + gage（抵押、保证），同源 wage。把自己押进去是从事，把人请进来是雇用。
ensure|en-（使）+ sure（确定）。把它弄确定。
entire|拉丁 integer 是「完整无缺」，同源 integer。一点没缺。
erupt|e- + rumpere（破），同源 interrupt、bankrupt。破开冲出来。
essential|拉丁 esse 是「存在」，同源 essence。少了它就不成其存在。
estimate|拉丁 aestimare 是「估价」，同源 esteem。心里称一称。
evaluate|e- + valere（价值），同源 value。把价值算出来。
exchange|ex- + cambiare（换）。换来换去；专门换钱的地方，就是交易所。
exclaim|ex- + clamare（喊），同源 claim。喊出声来。
exclude|ex- + claudere（关），同源 include、close。关在门外。
exhausted|ex- + haurire（抽水）。水被抽干，人也一样。
expense|ex- + pendere（称、付），同源 pension、expensive。把钱称出去。
explode|ex- + plaudere（拍手），同源 applause。罗马观众拍手把演员轰下台，后来指轰然炸开。
exploit|ex- + plicare（折），同源 explicit。把折起来的展开用完；用过头，就是剥削。
expose|ex- + ponere（放），同源 compose。放到外面。
facility|facilis 是「容易」，同源 facile。让事情变容易的东西；学什么都快，就是才能。
faithfully|faith（信）+ -ful（满）+ -ly。满心信守地。
fancy|源自希腊 phantasia「幻想」，同源 fantasy。脑子里想出来的花样，一时兴起也是它。
fantasy|同 fancy，phantasia 是「显现、想象」。放成一整篇的画面。
fascinate|拉丁 fascinum 是「咒语、魔物」。像被施了咒，挪不开眼。
fasten|fast 的古义是「牢固」，不只是「快」。弄牢，就是系紧；眼睛钉住，就是盯住。
feature|拉丁 factura 是「造出来的样子」，同源 fact。造出来的那副样子，就是特征。
federal|拉丁 foedus 是「盟约」，同源 confederate。几方立约结盟。
fellow|古诺斯语 felagi 是「合伙出钱的人」，fee + lay（放钱）。一起搭伙的。
fetch|古英语 feccan 是「去拿来」。跑一趟带回来；东西卖多少钱，也是「取回」多少。
fierce|古法语 fers 是「凶猛、骄傲」。下嘴不留情。
figure|拉丁 fingere 是「捏、塑形」，同源 fiction。捏出来的形状——身形、图形、数字，也指「人物」。
flexible|flectere 是「弯」，同源 reflect。能弯过来。
fond|古英语 fonned 原是「蠢的、痴的」。痴痴地喜欢。
forbid|for-（否定）+ beodan（命令），同源 bid。下令不许。
format|拉丁 forma 是「形状、模子」。按模子做出来的样子。
fortunate|拉丁 fortuna 是「运气」，同源 fortune。运气站在你这边。
foster|古英语 fostrian 是「喂养」，与 food 同源。喂大别人的孩子，也把想法喂大。
foundation|拉丁 fundus 是「底」，同源 fund。压在底下的那层；出钱的机构，也是「垫底的」。
freezing|freeze（冻）+ -ing。冻到能结冰。
frequently|拉丁 frequens 是「拥挤、反复」。一遍又一遍地来。
frighten|fright（惊吓）+ -en（使）。把怕塞给人。
fulfill|full + fill，把容器填满。承诺填满，是履行。
function|拉丁 fungi 是「履行、执行」。该它干的那份活。
