reaction|re-（回）+ agere（做、行动），同源 act。被推一下之后的回手。
rebel|re-（反过来）+ bellum（战争），同源 bellicose。反过来打。
recall|re- + call（叫）。把记忆叫回来；把产品叫回来，就是召回。
recommend|re- + commend（托付、称赞）。把人和事托付给你。
recover|re- + cover 的古义「取得」。重新拿回来；身体拿回原样，就是恢复。
recycle|re-（再）+ cycle（圈），同源 bicycle。再走一圈。
reflect|re- + flectere（弯），同源 flexible。光弯回来；心思弯回来，就是沉思。
reform|re-（重新）+ formare（成形）。重造形状。
refresh|re-（再）+ fresh（新鲜）。再来一次新鲜。
regardless|regard（看、顾及）+ -less（不）。不去看。
region|拉丁 regere 是「统治」，同源 regent。被划出来管的那一片。
register|拉丁 regesta 是「记录下来的东西」。写进册子；仪表把数记下来，就是显示。
regret|古诺斯语 grata 是「哭」。事过之后还在哭。
reject|re-（回）+ jacere（扔），同源 project。扔回去。
relate|re- + latus（带），同源 translate。把两头带到一起；把事带给人听，就是讲述。
release|re- + laxare（松），同源 relax。把扣着的松开。
reliable|re- + ligare（绑），同源 rely（原义「绑回去」）。能绑得住。
reluctant|re- + luctari（挣扎）。心里一直挣着。
remark|re- + mark（记号）。心里标了一下，才有了那句话。
remote|re- + motus（移），同源 move。移得远远的；关系也远。
represent|re-（再）+ present（呈现）。把不在场的再呈现一次。
resemble|re- + similis（相似），同源 similar。看起来像另一个。
reserve|re- + servare（保存），同源 preserve。先留着；留出来的一块地，就是保护区。
resist|re- + sistere（站），同源 insist。站着顶回去。
resolution|re- + solvere（松开），同源 solve、dissolve。把死结松开；心里定下来，就是决心。
response|re- + spondere（许诺、回答），同源 sponsor。被叫了一声之后的回话。
restless|rest（休息）+ -less（没有）。歇不下来。
restore|re- + staurare（立起），同源 restaurant（原义「恢复体力之处」）。重新立起来。
restrain|re- + stringere（绑紧），同源 strict。往后绑紧。
restrict|同 restrain，strict 是「拉紧、捆紧」。把范围捆小。
resume|re- + sumere（取），同源 assume。重新拿起来；简历也是一段「重新开始」的纸。
retain|re- + tenere（握），同源 maintain。一直握着不放。
retire|re- + tirer（拉）。把自己拉回去。
retreat|re- + trahere（拉），同源 contract。往后退着拉。
reveal|re-（去掉）+ velum（面纱），同源 veil。把面纱揭开。
revenge|re- + vindicare（主张、报复），同源 vindicate。把账讨回来。
reverse|re- + vertere（转），同源 convert。倒过来转。
revive|re- + vivere（活），同源 survive。重新活过来。
reward|re- + ward（看顾），同源 guard。回头照看你，给一份报酬。
rival|拉丁 rivus 是「溪」。共用一条溪水的人，难免要争。
rough|古英语 ruh 是「毛糙」。表面不平，日子也不平。
routine|route（路线）+ -ine。老走那条路。
rural|拉丁 rus 是「乡野」，同源 rustic。田那边。
sacrifice|sacer（神圣）+ facere（做）。做成献给神的；把自己交出去，就是牺牲。
salary|拉丁 sal 是「盐」。古罗马用盐当饷，后来的工资就从这儿来。
satisfy|satis（足够）+ facere（做）。做到够。
scan|拉丁 scandere 是「攀、按节奏走」。眼睛一行行走过去，机器一行行扫过去。
scare|古诺斯语 skirra 是「吓跑」。把胆吓掉。
schedule|拉丁 schedula 是「小纸片」。写着时间的那张条子。
scratch|中古英语 cracian 是「刮」。指甲划过去，划出一道印。
sculpture|拉丁 sculpere 是「刻」，同源 sculptor。一刀刀刻出来的。
security|se-（不用）+ cura（关心），同源 sure、cure。不用操心；操这份心的人，就是保安。
seek|古英语 secan 是「寻找」。四处找。
seize|古法语 saisir 是「抓住、占有」。一把攥住。
selfish|self（自己）+ -ish（有…性质的）。只装着自己。
sensitive|拉丁 sens 是「感觉」，同源 sense、sensor。一碰就有感觉。
severe|拉丁 severus 是「严厉、不苟」。一点不留情；病来得凶，也是它。
shame|古英语 sceamu 是「羞」。心里那条见不得人的。
sharp|古英语 scearp 是「锋利」。刀口快，脑子也快，涨价也快。
shock|法语 choc 是「撞击」。被猛撞一下；电流撞身，就是电击。
shortcoming|short（短、缺）+ coming（来）。短了那一截。
shrink|古英语 scrincan 是「蜷缩」。布料一洗就缩；人往后缩，就是退缩。
significant|sign（记号）+ fic（做）。做出记号的，都是要紧的事。
similarity|拉丁 similis 是「相似」，同源 similar。像的那一点。
simplify|simple（简单）+ -ify（使）。把复杂压平。
simulate|拉丁 similis 是「相似」，同源 similar。做得像真的。
simultaneously|拉丁 simul 是「同时」，同源 simultaneous。同一刻。
sincere|拉丁 sincerus 是「纯净、不掺」。心里没掺假。
sink|古英语 sincan 是「下沉」。往下沉；厨房里凹下去的池子，也是它。
skeptical|希腊 skeptikos 是「考察、怀疑」。先不急着信。
skip|古诺斯语 skopa 是「跳」。跳过一格。
slim|荷兰语 slim 是「细、薄」。身上薄；机会薄，就是渺茫。
slip|中古英语 slippen 是「滑」。脚底一滑；滑出来的小纸，就是纸条。
smooth|古英语 smoth 是「平滑」。表面没刺，过程没坎。
species|拉丁 specere 是「看」，同源 spectacle。看出来的那个样子，就是一类。
