champion|拉丁 campus 是「战场」，campio 是上场搏斗的人，同源 campaign。战场上赢下来的那个，后来泛指冠军和捍卫者。
character|希腊 charassein 是「刻划」。石头被刻出的那道印记，先指「特征」，再指人的「性格」和书里的「人物」。
charge|拉丁 carrus 是「车」，同源 cargo。往车上装东西，由「装载」生出要价、指控、掌管几层意思。
charity|拉丁 caritas 是「爱、珍贵」，同源 cherish。出于爱的给予，后来专指慈善。
charm|拉丁 carmen 是「歌、咒语」。念一句就把人勾住，本义是护身符，引申为魅力。
cheat|古法语 escheat 是「财产归公」。私吞本该充公的东西，就成了欺骗、作弊。
chemical|源自希腊 chemia「炼金术」。炼出来的东西，先指化学，再指化学品。
cheque|与 check「核对」是同一个词，英国人把它拼成 que。凭它去银行核对取钱，就是支票。
cherish|cher 是「亲爱」，与 charity 同一条线。捧在手心里护着。
chief|拉丁 caput 是「头」，同源 capital、captain。排头的那一个，既是首要的，也是首领。
citizen|city 的变体加 -zen（人）。住在城里、属于这个城的人，就是市民、公民。
civil|civis 是「公民」，同源 civilian。与公民有关——民事的、公民的；懂规矩就是文明。
clarify|clarus 是「清楚」，同源 clear、declare。把话说清，就是阐明。
classify|classis 是「类别」+ -ify（使）。把东西分组；把文件标上密级，也是同一个动作。
colleague|col-（共同）+ legare（派遣）。被同一个主人派出去办事的人。
collection|col- + legere（收集）。收拢到一处的动作，也指收来的那堆东西。
combine|com-（一起）+ bini（两个一排）。两个并成一个。
command|com- + mandare（命令、托付），同源 demand。交代给你办的事，语气硬一点就是命令。
commercial|com- + merx（商品），同源 market。一起做买卖的那一面。
communicate|communis 是「共同的」，同源 common。让大家共有，就是交流。
compete|com- + petere（追求），同源 appetite。大家追同一个东西。
complain|com- + plangere（捶胸哀号）。拍着胸口诉苦。
complex|com- + plectere（编织），同源 perplex。缠成一团，所以复杂；缠成一堆的楼，就是建筑群。
compose|com- + ponere（放）。把东西放齐是组成，把乐句放齐是作曲，把自己放平是镇静。
compound|与 compose 同源，pon 是「放」。放上再放一层，是复合；把麻烦再叠一层，是加重。
comprehension|com- + prehendere（抓住）。把意思抓住。
concentrate|con- + centrum（中心）。把心思赶到一个点上。
concept|con- + capere（抓），同源 capture。心里抓住的那个东西。
concern|con- + cernere（筛、分辨），同源 discern。心里反复筛这件事，所以是关心、涉及。
concert|con- + certare（争斗）。众人较着劲，却合成一个调子，就是音乐会，也指「协力」。
conclude|con- + claudere（关闭），同源 include。把门关上，是结束；把话收成一句，是断定。
conduct|con- + ducere（引导），同源 introduce。带着人走；带电走，就是传导。
confidence|con- + fidere（信任），同源 fidelity。完全信得过。
confirm|con- + firmare（使坚固），同源 firm。把它压结实。
conflict|con- + fligere（打击），同源 inflict。两边互相打。
confuse|con- + fundere（倒），同源 refuse、fusion。几种东西倒在一只碗里。
conscience|con- + scire（知道），同源 science。心里那个「知道对错」的声音。
consequence|con- + sequi（跟随），同源 sequence。跟在行为后面来的东西。
conservation|con- + servare（保存），同源 preserve。让它别变、别少。
consist|con- + sistere（站），同源 insist。几样东西一并站着，才成了一个整体。
constant|con- + stare（站），同源 stand。一直站着不动。
construct|con- + struere（堆建），同源 structure。往里堆，就是建造。
consult|拉丁 consulere 是「商议」。凑到一起问，也指翻书去问。
consume|con- + sumere（取），同源 assume。一路取光。
contact|con- + tangere（触），同源 tactile。手碰到手。
contemporary|con- + tempus（时间），同源 temporary。同一个时间段的。
content|con- + tenere（握），同源 contain。里面握着的是内容；心里握得住，就是满足。
contest|con- + testari（作证），同源 testify。各带证人来争。
contract|con- + trahere（拉），同源 attract。两边拉到一起是合同，往内拉是收缩。
contribute|con- + tribuere（给），同源 tribute。一起拿出来给。
convenient|con- + venire（来），同源 invent。能凑到一块儿来，就是方便。
cooperate|co-（一起）+ operari（工作），同源 operate。一起干活。
correspond|cor- + respondere（回应）。一来一回地对上。
courageous|拉丁 cor 是「心」，同源 record。心里有底、敢往上冲。
creative|creare 是「造」，同源 create、increase。能生出新东西。
credit|credere 是「相信」，同源 credible。别人信你是信用，你信别人的功劳是把功归于他。
crime|拉丁 crimen 是「指控、罪名」。被告席上那一条。
crisis|希腊 krinein 是「判断、决断」，同源 critical。到了必须做决断的那一刻。
critical|同 crisis，crit 是「判断」。能定生死的那一判；爱挑刺，也是从「判断」来的。
curiosity|cura 是「关心」，同源 cure、accurate。心里老惦记着，就是好奇。
current|currere 是「跑」，同源 occur、course。正在跑着的——现在的、水流、电流。
damp|中古荷兰语 damp 是「蒸汽、湿气」。空气里挂着水汽。
dash|拟声词，东西猛撞的声响。一冲、一撞，也指破折号那一划。
deadline|原是美国监狱在地上画的一条线，越过就开枪。后来指不可越的那条时间线。
debate|法语 debattre 是「打、争」，同源 battle。用嘴来回打；心里来回打，就是斟酌。
decade|deca 是「十」，同源 decimal。十个年头。
deceive|de- + capere（抓），同源 receive。设个套把人抓住。
decisive|de- + caedere（切），同源 decide、scissors。一刀切下去，不再改。
declare|de- + clarare（使清楚），同源 clear、clarify。把话说清给人听，向海关报也是这一层。
decline|de- + clinare（倾斜），同源 incline。往下倾是下降，把身子偏开是婉拒。
