# 词迹 · VocabTrace

> 看英文，想中文。一个「认读型」背单词应用：给英文，想中文意思，不考拼写。

词迹是为中文母语者做的英语词汇训练工具。它不追求"背了多少个"，而是让你在**看到英文的瞬间反应出中文含义**——这是阅读和听力真正需要的能力。

## 它做什么

- **背诵（认读）**：屏幕给出英文单词，你心里想出中文，翻面对答案，自评"记住 / 没记住"
- **默写（拼写）**：给中文或释义，写出英文，逐字判分
- **错词本**：背错或默错的词自动进入，背、默两侧各有一份"复习过"标记，两侧都过了才算真正划掉
- **书架**：可导入多本书，各自独立进度，互不干扰
- **账号与云同步**：邮箱登录，书架、进度、错词、头像、AI Key、昵称整套跟着账号走；换一台设备登录同一个邮箱，进去就是原来那个样子

## 账号同步了什么

云端每个账号存一份快照（`vocab_saves.snapshot`），内容就是应用运行时的整套状态：

| 字段 | 内容 |
|---|---|
| `books` | 书架：每本书的词卡（词形、释义、词源、例句、搭配、排序版本） |
| `prog` | 每词进度：认识次数、对错次数、错次、等级、背/默两侧的复习标记 |
| `session` | 当前这一组词背到第几个、第几页、对了几次——换设备能接着背 |
| `cfg` | 昵称、登录邮箱、头像（JPEG dataURL）、AI 接口与 Key、主题与字号 |
| `daily` | 每日背/默计数 |

合并口径：进度**只进不退**（取两边最大值），背/默"复习通过"标记以较新的一份为准，`daily` 按写入时间戳谁新听谁，`cfg` 以云端为准。新设备本人登录后自动拉取并合并，随后弹一句「已从云端恢复：已背 x / N，错词待复习 n 个，头像已同步，AI Key 已带上」。

设置页「云端同步」卡片能看到云端最新存档的时间、体积、书架词数、头像与 Key 是否带上，并可**导出一份存档 JSON**（整套数据，含头像与 Key，落盘自留）。

同步节奏：整包约 1 MB，改动后不会立刻全量上传——距上次推送不足 20 秒就压到 20 秒整点，另有 60 秒硬兜底；切走页面或关窗口前补推一次。

## 设计上的几个坚持

- **取词顺序按真题出现频次**，不是字母序。先背最可能考的。
- **判分在本地完成**，字面规则打底，拿不准的才交给 AI 复核，离线也能用。
- **配色交给 AI 生成**：按节气、天气、季节和你最近在背的词，每天换一套色板，不用你手动挑。
- **界面是一张纸**：线描莲花、书页框、朱印、编号卡片、代码底纹——不做成常见的"卡片 + 渐变按钮"。

## 下载

到 [Releases](https://github.com/yulinling512/vocabtrace/releases) 取安装包（当前 1.0.5）：

- 安卓：`vocabtrace-1.0.5.apk`，直接安装（同一签名，可覆盖升级）
- Linux：`vocabtrace-1.0.5-amd64.deb`，`sudo dpkg -i` 安装
- Windows：`vocabtrace-1.0.5-win-portable.zip`，解压即用（绿色版）

## 目录

```
app/index.html              界面全部（单文件 HTML，无构建依赖）
desktop/                    桌面端外壳：主进程、打包脚本、图标生成
android/                    安卓工程（WebView 壳 + 原生资源）
schema/  spec/              词库结构定义、导入格式与 AI 出题提示词
data/                       词库（601 词，含释义、词源、例句、搭配）
decks/  pipeline/           词库加工与合并流水线
_cards/  _etym/  _tips/     分词卡的原始文本批次
tools/                      辅助脚本（快捷方式、PDF 抽页）
docs/                       打包、部署与使用说明
icons/                      应用图标
```

## 从源码构建

```bash
# 桌面端（Electron）
cd desktop && npm install && npm run build

# 安卓（需 JDK 17 + Android SDK build-tools 34）
cd android && ./build-apk.ps1 -Ver 1.0.5 -Code 6
```

## 不包含什么

这个仓库**不含**：个人学习进度存档、云端 API 密钥、签名证书、以及 exe / deb 这类体积较大的打包产物（大件走 Release 附件）。授权信息在运行时由使用者自己填写。
