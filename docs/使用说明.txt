词迹 · 桌面版
========================================

【怎么开始】

1. 双击 程序\词迹.exe（或桌面上的「词迹」快捷方式）
2. 第一次打开，先注册：登录页点「注册新账号」，邮箱已填好，点「获取验证码」，
   去邮箱收 6 位数字，同时设一个密码（至少 6 位），点「注册并登录」。
   注册用一次验证码，之后登录只需邮箱+密码，不用再等邮件。
   以后打开：本机记住登录态会自动进；没记住时输邮箱+密码即可。
   新设备同样是邮箱+密码登录，验证码只在注册和忘记密码时用。
   换账号用设置里「切换」或「退出登录」。
   · 你现有的邮箱账号（之前用验证码注册的）还没有密码：第一次用新版本时，
     在登录页点「忘记密码？」→ 输邮箱 → 获取验证码 → 设一个新密码 →
     点「设置新密码并登录」，之后就能用密码登录了。
   · 电脑上原有的老账号仍可用：登录页点「用这台电脑上的老账号进入」，
     原来的进度一格不少。
3. 进去之后，先去「设置」填 AI 判分的 API Key，点「测试连接」看到「通了」。
4. 回首页 → 点「背诵」→ 背完点「去默写这一组」。


【一天一组，没默不算完】

· 一次背一组，默认 36 个，按书的顺序往下走，组内打乱。
· **一组 = 默写纸的一页。** 词库是按《高频词默写》的真题频次顺序排的，
  每 36 个词标成「第几页」，页序号跟纸质默写纸完全一致：
  应用里今天背第 7 页，纸面上也就是第 7 页（No.07/17），36 个词一一对上。
  最后一页（第 17 页）只有 25 个词。
· 页与页按顺序推进，页内顺序每次重新打乱——所以电子版做完再去手写，
  是同一页的同一批词，只是顺序不同，不用回头对词。
· 背完就该默写。默写只测刚背过的这一页。
· 要是背了没默写，这一页不算完：下次还是这一页（页内重新打乱），
  默完才往下走。相当于昨天没默完的补上，再往下一页。
· 默写全程不用碰鼠标（**要先点右上角全屏**，窗口化时按键还是正常打字）：
  全屏后写完按「空格」判分，看过结果再按一次「空格」就是下一个；
  不会按句号键（.）跳过。中文拼字时按键归输入法，不会误判。
  判分键和跳过键都能改：设置 →「默写快捷键」，点一下按钮再按键即可；
  想避开中英文句号的问题，建议把跳过改成逗号（,）或斜杠（/）。
  如果判分键是空格，真要打空格请按 Shift+空格。
· 频率你自己定，隔一天、隔一周都行，没补完的那一页会一直等着。
· 每组多少个可以改，而且只改当前这本书：设置 →「一本书一组」（5–500，
  换一本书可以另设一套；底下的链接可以把所有书统一成同一个数）。
  自己设过组大小之后，页码就按这个数切，不再跟默写纸对齐；
  想恢复「一页 36」就设回 36。这个数也是首页「今日目标」的分母。

【首页的今日进度】

· 首页「背诵」「默写」两个板块底部，各有一条进度线和「今日目标 X / N 个」，
  N 就是这本书每组多少个（可改）；数字随你背、默实时增长，当天满了就到头。
· 「错词本」板块显示当前待复习数。
· 首页书卡上直接写着「已背 X · 已默 Y · 共 Z」，旁边圆环是全书默过的百分比。
· 今日统计、错词、书架、背默记录、快捷键设置，全都写在这个账号自己的
  「数据\账号\账号ID.json」里，跟账号放一起，换账号互不干扰。
· 老存档第一次打开会自动按现有记录补出今天的数字，不会让你重新背一遍。
· 设置 →「账号数据」一栏，把上面这些数按账号汇总给你看：书架索引、
  背默数量与百分比（含背对数）、今天的量、错词待复习数（按背/默分开）与累计数。

【云端同步 · 手机和电脑接着背】
· 邮箱账号的进度同时存在这台电脑和云端。每次打开自动同步一次，
  背/默过程中也会自动推上去；设置 →「云端同步」→「立即同步」可手动来一次。
· 手机装了应用后，用同一个邮箱登录，错词、书架、背默进度全都在。
  没网也能背，联网后再同步。
· 合并规则：进度只往前的算，错次取最大不叠加，两边的书架、每日统计都保留，
  谁的记录都不会被冲掉。
· 第一次用邮箱登录时，会把这台电脑上老账号的进度自动搬到云端，一条不丢；
  老账号和老存档文件都原样保留，随时能从「老账号」入口进去。
· 本机老账号只存在这台电脑，不上云。

【错词怎么复习】

· 首页点「错词本」，每个词条都直接写全词性和全部义项；点一下词条，
  会展开完整词卡：核心释义、词源、怎么记、例句、搭配、易混词，和背诵页一样。
· 背诵和默写分开记：每个词后面有「背 ✓/待」「默 ✓/待」两个小标记。
  背对只划掉背诵这一侧，默对只划掉默写这一侧；两侧都过了，才算彻底复习完。
· 页面顶部两个按钮各自带数量：「背诵复习 N」只取背诵侧待复习的词，
  「默写复习 N」只取默写侧待复习的词，用的还是原来那套流程。
· 背完点「去默写这一组」，接的就是同一批词；默写完点「再背这一组」也能回去。
· 背诵完成页有「再背这一组 / 背下一组」，默写完成页有「再默这一组 / 再背这一组」：
  背完了照样能重背，不重新挑词，也不会抹掉已有的掌握记录。
· 复习时不会动你正在背的那一组：进度单独留着，退出复习自动回到原处。
· 两侧都过的会收进页面底部「已复习通过」折叠区，错几次、什么时候过的都留着，
  一条记录都不删。


【书是怎么算的】

一个词库 = 一本书。书架上可以放很多本，各背各的，进度互不干扰。

· 首页那条横排就是书架，点书脊直接换书
· 点「书架 ›」进书架页，看全部书和过关记录
· 一本书里的词全部「背过 + 默过」，就盖一个「已过关」章，记进过关记录
· 再导入一个词库，就是书架上的第二本书，原来那本原样保留


【怎么返回上一级】

· 每个页面标题左边都有「‹ 返回」按钮，点它退回上一级
  （首页→书架→点进某本书，返回先回到书架，不是直接甩回首页）
· 窗口左上角还有一个小箭头，作用一样，往下翻长页面时它一直留在顶栏
· 首页是根，没有返回按钮；登录页也不显示


【首页上那行字是什么】

最上面是你：头像、名字、今天几号、什么节气、外面的天气（能连上才显示）、
已经连续学了多少天。头像点一下就能换，换完「今日配色」还能按头像取色。

天气来自 wttr.in，不需要 key；取不到就不显示，不影响别的。


【今日配色 · AI】

设置里有一块「今日配色」。点「按今天配一套」，它会把这些东西一起交给 AI：
日期、节气、季节、时段、天气、头像主色、你最近在背的十几个词，
然后生成一套配色：一个底色 + 一主两辅三支强调色，直接铺到整个界面上。

· 一套色会用在这些地方：菜单图标的色块、书卡顶部的细线、进度环、
  书架上的书脊、词卡的情绪色、过关时撒的纸屑
· 配完就存在本机，不会每次都调；想换就再点一次
· 不想花 token：「按头像配」用头像里的主色现算，「随手一套」从内置的
  十二套里挑，两个都不联网
· 想回原来的主题：点「还原」，或者直接在外观里选纸白/墨绿那几套

AI 配色用的是你在「AI 判分」里填的 key 和模型。模型第一次可能要几十秒，
按钮上会显示等了多少秒；中途断了会自动重试一次，再不行换一个快模型。
真配不出来也不影响用，界面会停在当前配色。


【文件夹都是干什么的】

程序\        程序本体，别删别改
数据\        你的书架和进度
  ├ 进度数据.json      最早那份数据（会被第一个账号接走）
  └ 账号\              每个账号的进度、账号表
词库\        放你自己的 CSV 词库，方便随手找
界面\        运行时的界面文件，改这里不用重新打包
源码\        代码，不懂可以完全不管
安装包\      词迹-安装包-1.0.0.exe，安装版（见下）

桌面上的「词迹」快捷方式，指向 程序\词迹.exe，可以改钉到任务栏。


【安装版和绿色版】

两种都能用，数据互通，选一个就行。

· 绿色版：双击 程序\词迹.exe 直接用，数据在 D:\VocabLab\数据。
· 安装版：双击 安装包\词迹-安装包-1.0.0.exe，走一遍安装向导，
  会在桌面和开始菜单建「词迹」，以后从那儿打开，卸载也在那儿。

安装向导里可以把安装位置改成 D:\VocabLab\程序。装在别处的话，
数据会放在安装目录下的「数据」文件夹里。


【数据会不会丢】

不会。账号的进度写在 数据\账号\ 里的文件，关掉程序、重启电脑、清缓存都不影响。
换电脑：把整个「数据」文件夹拷过去，或在「设置」里点「导出备份」。


【接近率是什么】

默写判分不只看对错，还给一个 0–100 的百分比：你的答案离标准释义有多近。
78% 是及格线，到了就算过。本地先按字面比，拿不准的交给 AI 复核。


【想换别家的模型】

设置 → 接口地址填完整地址（例如 https://api.moonshot.cn/v1/chat/completions），
模型名跟着改。留空就是默认的 DeepSeek。


【改过代码以后，怎么重新打包】

在 源码\desktop 里执行：

    node build.js      绿色版，产物直接覆盖到 程序\
    npm run setup      安装包，产物落到 安装包\

打包时程序必须关掉，否则 exe 占用会覆盖失败。
只改界面的话不用打包：把 源码\app\index.html 复制到 界面\index.html，重启程序即可。


【常见问题】

· 双击没反应 / 一闪就没
  先看是不是被杀毒软件拦了，把它加入信任。

· 窗口一片空白
  以前界面进来的动画会被系统「挂起」，窗口失去焦点再回来就成了白屏。
  现在加了两道保险：窗口在后台不冻结，动画一秒后强制收尾。
  真遇到白屏，按 Ctrl+R 刷新一下就好。

· 邮箱收不到验证码（只在注册或找回密码时需要）
  先看垃圾邮件箱，发信方是腾讯云。等十几秒还没到，回登录页点「重发验证码」。
  平时登录只用邮箱+密码，不需要验证码。

· 忘了邮箱账号的密码
  登录页点「忘记密码？」→ 邮箱（已填好）→ 获取验证码 → 收 6 位数字 →
  设新密码 → 点「设置新密码并登录」。进度不会丢。

· 忘了老账号的密码
  老账号的账号表在 数据\账号\账号表.json，密码不可逆，只能删掉那个账号重新建，
  进度文件还在（数据\账号\账号ID.json），可以改名接回来。或者直接改用邮箱登录，
  第一次登录会自动把老进度搬过去。

· 「测试连接」提示 401
  通道是通的，是 key 不对。检查有没有复制全、有没有多余空格。

· 词库导入报错
  CSV 表头必须是：word,meanings,phonetic,note
  多个义项用 | 分隔，同一义项的不同说法用 、 分隔。

· 想删掉某本书
  设置 → 书架管理 → 点「删」。删掉的书连同进度一起没了，删之前先导出备份。

· 安卓安装包
  安装包\词迹-安卓-1.0.0.apk 是手机端。装好后用邮箱 + 密码登录，
  第一次会自动铺好 601 词的词库，进度从云端拉下来，和电脑端同账号同步。
  手机端不读写电脑上的「数据」文件夹：记录存在应用本机，同时推云端。
  物理返回键先退回应用内上一级，到首页再按一次退出。
  AI 配词要在设置里填模型地址和 key；不填也能正常背、默、复习错词。
  重新打包：源码在 android\ 目录，执行 build-apk.sh 会覆盖生成安装包。
  签名证书在 android\keystore\vocabtrace.jks（密码 123456），以后升级沿用同一个证书。

· 文件位置约定
  这个项目的所有文件都放在 D:\VocabLab 里：源码、数据、词库、安装包、安卓工程，
  以及打包用的 JDK / Android SDK / 临时浏览器目录（源码\tools、源码\android-sdk）。
  不要在 C 盘放应用文件或生成项目数据。
