# Vocab Lab · 背单词流水线

一句话：**任意词源 → 按固定格式整理 → 上传 → 直接背。**

网站只认一种输入格式。来源多离谱都不影响网站，因为整理这一步在上游完成。

---

## 完整流程

```
任意词源（xlsx / pdf / 截图 / App 导出 / 手抄）
        │
        │  你 + AI，用 spec/ai-prompt.md 里的指令
        ▼
标准 CSV（spec/import-format.md 定义的格式）
        │
        │  上传到网站
        ▼
校验器（不合格整份退回，指出第几行第几列）
        │
        ▼
词库（本地存储）
        │
        │  背诵时自动补词源、记忆法，按单词缓存
        ▼
背诵 / 默写判分 / 错词本
```

## 目录

```
vocab-lab/
├── spec/
│   ├── import-format.md   导入格式规范（人读，定义了唯一收货标准）
│   ├── ai-prompt.md       给 AI 的整理指令（换词源时复制即用）
│   └── template.csv       空模板 + 示例
├── schema/
│   ├── vocab.schema.json  内部数据契约（前端消费的结构）
│   └── sample.vocab.json  示例
├── pipeline/              校验与归一化逻辑（CSV → 内部契约）
├── decks/                 词库数据
├── cache/                 词源与记忆法缓存，按单词全局去重
└── app/                   背诵界面
```

---

## 三条铁律

**一、格式即接口，AI 即适配器。**
不再为 xlsx、pdf、截图各写一个解析器——那是无底洞，永远补不完。整理工作交给上游 AI，网站只做校验和消费。新增任何词源，网站代码零改动。

**二、富化按单词缓存，跨词库复用。**
词源和记忆法以单词为键存在 `cache/`。同一词无论出现在第几份词库，只生成一次、只花一次钱。越用越便宜。

**三、校验不过，整份退回。**
不修完不许进背诵。带病的词库比没有词库更糟——你会在错误的释义上背两个月。

## meanings 的两种分隔符

| 符号 | 含义 | 判分影响 |
|---|---|---|
| `\|` | 不同义项 | 答对任一义项即算掌握 |
| `、` | 同一义项的近义说法 | 答任一说法都算对 |

这一条是整个判分准确性的地基。把多义塞成一格，后面所有工作都是白费。
