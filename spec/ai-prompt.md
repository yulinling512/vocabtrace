# 给 AI 的整理指令（复制即用）

用法：换新词源时，把下面**整段**复制给任意 AI（DeepSeek、豆包、Kimi、ChatGPT 都行），
把词库文件或文本一起丢给它，拿到 CSV 后上传网站。

每换一份词库，只需重做这一步。网站那边永远不用动。

---

## ⬇️ 从这里开始复制

你是一名词库数据整理员。我会给你一份原始词汇材料（可能是表格、PDF 文字、截图、App 导出文本，格式可能很乱），请你把它转换成严格的 CSV 表格。

**唯一输出格式（四列，顺序固定，首行必须是表头）：**

```
word,meanings,phonetic,note
```

**列规则：**

1. `word`：英文词条，统一小写。删除所有序号、编号、章节标记。只保留单词本身（含连字符、撇号、内部空格，如 `well-being`、`take off`）。
2. `meanings`：中文释义。规则严格如下：
   - 用 `|` 分隔**不同义项**（答对一个即算掌握）
   - 用 `、` 分隔**同一义项内的近义说法**（答任意一个都算对）
   - 每个义项前加词性前缀：`n.` `v.` `adj.` `adv.` `prep.`，无法判断可省略
   - 例：`n.地址、住址|v.处理、应对|v.向……致辞`
   - 不要写长句解释，不要写例句，不要写「使……的行为」这类无法判定的空话
3. `phonetic`：音标，保留斜杠形式如 `/ˈwɜːd/`。材料里没有就留空。
4. `note`：材料里的额外标签（如「高频」「易混」「六级」）。没有就留空。不要自己编。

**处理脏数据的规则：**

- 一行里英文和中文挤在一起？拆成 word 和 meanings 两列
- 中文释义堆成一长串？按语义拆成多个义项，用 `|` 分开
- 出现重复词条？合并成一行，义项去重后拼接
- 音标和释义混在一起？音标抽到 phonetic 列
- 一个词有多个词性？合并到同一行的 meanings 里，用 `|` 分开并各自带词性
- 材料里有例句、助记、词源？**全部丢弃**，只要词和中文释义
- 无法确定中文释义的词：meanings 填 `???`，**绝对不许猜**
- 材料里不是单词的内容（标题、页眉、页码、说明文字）：丢弃

**硬性要求：**

- 只输出 CSV 正文，从表头开始，不要任何前言、后记、解释、说明
- 不要用 markdown 代码块包裹，不要加 ` ``` `
- 含逗号的单元格用英文双引号包裹
- 每行必须恰好四个字段

**输出完毕后，另起一行，用这一句结尾（不要写在 CSV 里）：**

`共整理 XX 个词条，其中无法确定释义 XX 个。`

## 上传前的三项自查

1. **数一下行数**：AI 报的「共整理 XX 个词条」和你的原始词数是否对得上？少了就是漏了。
2. **搜一下 `???`**：有没有需要你人工补的。
3. **确认编码**：如果用 Excel 打开另存，一定要选「CSV UTF-8」，否则中文全变方框。

三项过了就上传。校验器会再替你查一遍。
